# Contributing

Thank you for your interest in contributing to **Restaurant Management Timeless**.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test your code.
5. Commit your changes.
6. Push your branch.
7. Open a Pull Request.

## Coding Guidelines

* Follow Java naming conventions.
* Write clean and readable code.
* Keep methods modular.
* Test new functionality before submitting.

## Reporting Issues

If you encounter a bug or have a feature request, please open a GitHub Issue with a detailed description.
